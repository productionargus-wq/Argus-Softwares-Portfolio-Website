# ARGUS Softwares - Company Portfolio Website

An interactive, animated single-screen portfolio website for **ARGUS Softwares** built with React and Vite.

## ✨ Features

- **Modern Bright Light Theme**: High-contrast, clean typography, luminous ambient gradients, and crisp frosted glass surfaces.
- **Single-Screen Rail Navigation**: Left and right side rails with instant section jumping and smooth auto-rotation cycle.
- **Directional Flight Motion**: Dynamic SVG trajectory curves, glowing particle trails, flying badges, and arrival pulses from side buttons directly into the center stage.
- **Interactive Product Showcases**:
  - **MetalCalc**: Live interactive section weight estimator (Round Bar, Pipe, Square, Sheet, Hex in Steel, Aluminum, Brass, Copper).
  - **ARGUS ERP**: Operational dashboard preview across inventory, procurement, and dispatch.
  - **Attendance App**: Shift workforce simulator with contactless punch-in/out logic.
  - **Downloads Center**: Native Windows installer preview with local file loading and simulated download flow.
  - **Solutions & Help**: Digital capabilities and structured client communication.
  - **Contact**: Quick inquiry composer with formatted clipboard copying and direct email integration.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/productionargus-wq/Argus-Portfolio-Website.git
cd Argus-Portfolio-Website

# Install dependencies
npm install

# Run the development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
